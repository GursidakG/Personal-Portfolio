    CHROME EXTENSION · 2026

    NoteVis

    Turns any webpage, or a highlighted selection, into structured study notes: a summary, key points, and a glossary, generated on-device in a side panel. Local-first, no account, no server. Published to the Chrome Web Store, where it holds a 5.0 rating from its first reviewers.

    JavaScriptChrome APIsOn-device AI
    Chrome Web Store (opens in a new tab)
    How it was built
    Problem
    Long articles and documentation take time to digest, and highlights left in another tab are not notes.
    Approach
    A Chrome extension that reads the current page or a selection and produces a summary, key points, and a glossary in a side panel, entirely on-device. Notes sort into folders, search, and export as Markdown.
    Hardest part
    Passing Chrome Web Store review. Asking for the minimum permissions and publishing a privacy policy shaped the architecture: no server, no analytics, nothing leaves the browser.
    Outcome
    Live on the store with a 5.0 rating from its first reviewers.
    What I’d change
    Add a lightweight feedback loop sooner; what people export says more about what they wanted than installs do.

    CHESS APP · 2025–2026

    Chess Engine

    A playable Python chess app with a dark tournament-hall board: legal moves, check, checkmate and stalemate detection, castling, en passant, and promotion. The AI mode is a threaded minimax search with alpha-beta pruning that wins roughly 70% of its games against intermediate players.

    PythonPygameMinimax
    Code on GitHub (opens in a new tab)
    How it was built
    Problem
    I wanted to understand game-tree search by building a playable opponent, not by reading about one.
    Approach
    Pygame for rendering and python-chess for move legality, so the effort went into the search: a threaded minimax with alpha-beta pruning playing Black, plus an evaluation bar, timers, move history, captured pieces, and a flip-board option.
    Hardest part
    Keeping the board responsive while the search runs. Moving the AI onto its own thread kept the clock ticking and the pieces clickable.
    Outcome
    About a 70% win rate against intermediate players.
    What I’d change
    Add move ordering and a transposition table so the same time budget searches deeper.

    FULL-STACK APP · 2025

    Nutritionwize App

    AI chat, reliable data imports, and a faster search experience for a diet clinic. A Go API rework reduced p95 search latency by 12% during high-traffic usage.

    React NativeNode.js / GoOpenAI API

    Client work; the codebase is private.

    How it was built
    Problem
    A diet clinic needed one app for AI chat, telehealth, and a dietitian portal, with data imports that could not corrupt the primary database.
    Approach
    I gathered requirements from the dietitians and wrote the PRD and feature specs, then built CSV validation with row-level error handling in Node.js, integrated GPT-4o chat, and reworked the high-traffic search API in Go.
    Hardest part
    Turning clinical workflows into specs that practitioners and engineers both recognised as correct.
    Outcome
    Piloted with more than 100 patients and practitioners; p95 search latency down 12%; practitioner efficiency up 10%.
    What I’d change
    Load-test the search path before peak traffic instead of after the timeouts appeared.
